# HomeLab AAA automation

Security-reviewed design and read-only discovery tooling for a FreeRADIUS
deployment on an Ubuntu ARM64 VirtualBox guest and a Raspbian PiVPN host.

The deployment is gated until guest SSH access, authentication policy, network
trust boundaries, and recovery evidence are verified. No credentials, private
keys, inventories, state files, VM images, or host captures are stored here.

See [aaa-deployment.md](aaa-deployment.md).
